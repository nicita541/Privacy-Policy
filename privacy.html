Политика конфиденциальности

Данное приложение Erudition не требует создания аккаунта и не собирает персональные данные пользователя.

Реклама

В приложении используется рекламный сервис Яндекс Реклама. Рекламные SDK могут собирать техническую информацию, необходимую для показа рекламы и анализа её эффективности.

Приложение не собирает:

  • Имя пользователя
  • Адрес электронной почты
  • Номер телефона
  • Данные местоположения

Права пользователя

Пользователь может обратиться по вопросам обработки данных через контакт разработчика.
