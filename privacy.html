Политика конфиденциальности

Дата вступления в силу: 28 сентября 2026 года

Настоящая политика конфиденциальности описывает обработку данных пользователей мобильной игры «Криптограммы: Шифры совы».

2. Игровые данные

Игра не требует создания аккаунта и регистрации пользователя.

Игровой прогресс сохраняется локально на устройстве пользователя. Могут сохраняться:

  • текущая головоломка;
  • введённые буквы;
  • прогресс коллекций;
  • достижения;
  • игровые ресурсы;
  • настройки звука, вибрации и отображения текста.

Собственный сервер синхронизации игрового прогресса в приложении не используется.

3. Реклама и сторонние сервисы

В приложении используется сервис Yandex Mobile Ads для показа рекламы, включая межстраничную рекламу и видео с вознаграждением.

Рекламные сервисы могут обрабатывать техническую информацию, необходимую для работы рекламы, включая:

  • информацию об устройстве;
  • версию приложения;
  • данные взаимодействия с рекламой;
  • рекламные идентификаторы устройства.

Эти данные используются для предоставления рекламы, измерения её эффективности и защиты рекламной системы от злоупотреблений.

4. Использование AppMetrica

Приложение может содержать компоненты AppMetrica. Использование аналитических функций зависит от конфигурации финальной версии приложения и настроек SDK.

5. Какие данные приложение не собирает

Приложение не собирает:

  • имя пользователя;
  • адрес электронной почты (если пользователь сам не обращается в поддержку);
  • номер телефона;
  • контакты устройства;
  • фотографии;
  • данные микрофона;
  • данные местоположения.

6. Управление данными и удаление

Пользователь может удалить локальные данные игры через настройки Android:

  • Настройки устройства;
  • Приложения;
  • Криптограммы: Шифры совы;
  • Очистить данные приложения.

Также удаление приложения удаляет локальные данные игры с устройства.

Для вопросов, связанных с обработкой данных, пользователь может обратиться:

7. Возрастная категория

Приложение содержит рекламные материалы. Возрастная категория определяется при публикации приложения в магазине приложений.

8. Изменения политики

Разработчик может обновлять данную политику при изменении приложения, используемых сервисов или требований законодательства.
